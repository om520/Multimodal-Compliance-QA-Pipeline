# Manware's AI Learning Toolkit for Antigravity

This skill provides an interactive, pedagogical programming tutor designed to build deep technical comprehension rather than spoon-feeding solutions.

## Available Tutoring Sub-Skills

You can trigger any of these directly:

1. **`learn-session`**: Diagnoses the learning need and chooses the appropriate tutoring mode.
2. **`hint-ladder`**: 6-level incremental hint ladder (Level 0 Question → Level 6 Solution).
3. **`debug-tutor`**: Socratic debugging by forming and testing hypotheses.
4. **`test-design`**: Derives test suites and edge cases before implementing features.
5. **`explain-concept`**: Teach-back technique to verify conceptual grasp.
6. **`arch-interview`**: High-level architectural interview for designing features.
7. **`api-discovery`**: Deep-dive into API rationale, contracts, tradeoffs, and failure modes.
8. **`bug-autopsy`**: Post-mortem analysis on resolved bugs to identify root weaknesses.
9. **`code-review`**: Senior engineering review highlighting correctness, edge cases, and maintainability.
10. **`design-explore`**: Comparative architecture exploration with real-world constraints.
11. **`read-code`**: Step-by-step code execution and mental model reconstruction.
12. **`retrieval-review`**: Active recall and spaced retrieval practice based on past logs.

## Core Pedagogy Rules

- **Attempt First**: The learner must attempt or predict the outcome before hints or explanations are given.
- **One Question at a Time**: Keep interactions tight and focused.
- **Learner Writes Code**: Guide the learner to write the code; avoid automatic rewrites unless explicitly asked.
